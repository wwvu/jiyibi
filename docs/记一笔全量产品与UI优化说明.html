产品方向变化

解决“功能都有，但没有理由每天打开”的问题。

优化前：流水工具

明细、预算和图表互相独立；首页直接进入账单；用户只能看到“花了多少”，很难知道接下来应该怎么做。

优化后：财务节奏助手

首页先告诉用户今天的财务状态、预算进度和安心可花额度，再提供明细证据、预算调整和消费洞察。

记录数据 → 判断节奏 → 给出建议 → 用明细和图表解释

页面级改动

所有主要用户路径均重新梳理，而不是只改首页。

模块原问题本次优化
主导航明细、预算、报表并列，缺乏真正首页调整为“首页 / 明细 / 洞察 / 我的”，预算作为首页关键能力下钻
首页打开后直接看流水，缺少每天回访理由新增今日财务气象、安心可花、预算与时间进度、本月发现和最近记录
预算环形图展示结果，但行动建议不突出围绕剩余预算、每日建议、预计月末、分类边界重新组织
洞察饼图和折线图直接堆叠，需要用户自己解释先给一句话结论，再展示总额、日均、峰值、分类排名和趋势证据
日历每日数字密集，难以快速定位异常日升级为消费热力图，新增月度摘要、当日收支汇总及直接编辑
明细月份和流水混在同一层，筛选能力弱增加月份切换与全部/支出/收入筛选，保持按日分组账本结构
记账表单感较强，数字键盘存在嵌套 Expanded 运行时风险强化金额主视觉、统一分类选择与键盘，并修复 ParentData 冲突
我的普通设置列表，缺少个人账本感新增财务档案头部、连续记账信息、主题色板、数据与安全分区

设计系统

目标是安静、可信、可扫描，避免营销页式大渐变和过度装饰。

颜色

主题色ColorScheme.primary
支出色#D85A30
收入色#3B6D11

组件几何

页面边距16px
常用间距4 / 8 / 12 / 16 / 24
卡片圆角18px
按钮圆角12–14px
主信息卡20–22px

层级原则

第一层今日状态 / 金额
第二层可执行建议
第三层图表与明细证据
装饰少阴影 + 浅表面

“财务气象”计算链路

功能完全基于本地整数金额计算，不读取备注内容，不依赖外部服务。

本月流水汇总支出、收入、今日支出和分类结构
预算与时间计算预算进度、月份进度和剩余天数
SpendingPulse使用 int cents 判断晴朗、平稳、提醒、超支
可执行输出安心可花 / 天、预计月末和自然语言说明
