一、技术栈选型与分阶段依赖

一句话定调

Flutter + Riverpod + drift + fl_chart，Android 单平台先行。

对 Java 开发者来说，这套组合的学习成本主要在 Dart 语法（接近 Java）和 Flutter 的声明式 UI 思路。状态管理和数据层都有 Java 体系里熟悉的概念对应。

为什么是 Flutter 而不是原生 Kotlin/Compose

维度Flutter（选定）原生 Kotlin + Compose
跨平台一套代码，将来上 iOS 几乎零重写仅 Android，上 iOS 要重写整个 UI
新技术体验Dart + 声明式 UI，真正不同的技术栈只是换了语言，思路还是 Android 那套
开发体验热重载（Hot Reload），改代码秒级生效有热重载但稍慢
记账生态fl_chart 等组件成熟，记账类教程多MPAndroidChart 等成熟
学习成本Dart 语法接近 Java，1-2 天可上手写页面Kotlin 几乎零门槛
结论：用户"愿意尝试新技术栈"，Flutter 才是真正的技术栈切换；Kotlin/Compose 只是换语法。Flutter 的跨平台特性让"单平台先行、将来轻松补 iOS"成立，原生 Kotlin 做不到。

class Records extends Table {

  DateTimeColumn get date => dateTime()();
  TextColumn get type => text().withDefault(const Constant('expense'))(); // 'expense'|'income'
  IntColumn get amountCents => integer()();              // 金额，分，始终正数

  DateTimeColumn get createdAt => dateTime().withDefault(currentDateAndTime)();
  DateTimeColumn get updatedAt => dateTime().withDefault(currentDateAndTime)();

  @override
  List<Set<Column>> get uniqueKeys => [{sourceId}]; // DB 层去重兜底
}

  List<Set<Column>> get uniqueKeys => [{name, type}]; // 同名同类型唯一

class Accounts extends Table {
  IntColumn get id => integer().autoIncrement()();
  TextColumn get name => text().withLength(min: 1, max: 20)();
  IntColumn get balanceCents => integer().withDefault(const Constant(0))();  // 余额，分
  TextColumn get icon => text().withDefault(const Constant('💰'))();
  BoolColumn get archived => boolean().withDefault(const Constant(false))();

  @override
  List<Set<Column>> get uniqueKeys => [{name}];
}

class Budgets extends Table {
  IntColumn get id => integer().autoIncrement()();
  IntColumn get month => integer()();                    // 202607
  IntColumn get amountCents => integer()();              // 预算，分
  IntColumn get categoryId => integer().withDefault(const Constant(0))();  // 0=总预算；真实分类 id 从 1 开始

  @override
  List<Set<Column>> get uniqueKeys => [{month, categoryId}]; // 含总预算(categoryId=0)
}
为什么预算表 categoryId 用 0 而不是 null：SQLite 中 NULL 在 UNIQUE 约束里不冲突——多条 categoryId=null 的总预算行能共存，约束形同虚设。用 0（NOT NULL DEFAULT 0）后，真实分类 id 从 1 开始不冲突，unique(month, categoryId) 对所有行生效。

6.1 MoneyUtils —— 金额转换（字符串直转，不经 double）

lib/core/utils/money_utils.dart

/// 金额工具：输入元字符串、存储 int 分、显示元字符串。
/// 全程不经 double，彻底杜绝浮点精度问题。
class MoneyUtils {
  /// 分 → 显示字符串：1234 → "¥12.34" / -123456 → "-¥1,234.56"
  static String formatYuan(int cents) {
    final neg = cents < 0;
    final abs = cents.abs();
    final yuan = abs ~/ 100;
    final frac = abs % 100;
    final yuanStr = yuan.toString().replaceAllMapped(
      RegExp(r'(\d)(?=(\d{3})+$)'), (m) => '${m[1]},');
    return '${neg ? '-' : ''}¥$yuanStr.${frac.toString().padLeft(2, '0')}';
  }

  /// 元字符串 → 分：不经 double，字符串直转。
  /// "12.34"→1234 / "12.3"→1230 / "12"→1200 / ""→0 / "-12.34"→-1234
  /// 小数超两位截断（不四舍五入）；非法格式（多小数点/非数字字符）返回 0
  static int yuanToCents(String yuan) {
    final s = yuan.trim();
    if (s.isEmpty) return 0;
    var neg = false;
    var body = s;
    if (body.startsWith('-')) { neg = true; body = body.substring(1); }
    else if (body.startsWith('+')) { body = body.substring(1); }
    if (body.isEmpty) return 0;
    // 非法格式：含非数字字符或多个小数点
    if (!RegExp(r'^\d*\.?\d*$').hasMatch(body)) return 0;
    final dot = body.indexOf('.');
    int yuanInt, fracInt;
    if (dot < 0) {
      yuanInt = int.parse(body);             // 已验证纯数字
      fracInt = 0;
    } else {
      final yuanPart = body.substring(0, dot);
      var fracPart = body.substring(dot + 1);
      yuanInt = yuanPart.isEmpty ? 0 : int.parse(yuanPart);
      if (fracPart.length > 2) fracPart = fracPart.substring(0, 2);  // 截断到两位
      fracPart = fracPart.padRight(2, '0');                          // "3" → "30"
      fracInt = int.parse(fracPart);
    }
    final cents = yuanInt * 100 + fracInt;
    return neg ? -cents : cents;
  }
}
为什么字符串直转：数字键盘全程是字符串累积（点 "1""2"".""3""4" → "12.34"），最后一次性 yuanToCents("12.34") 转 1234。旧方案 (double * 100).round() 经过浮点表示，极端值有精度漂移。字符串拆整数/小数部分直转 12*100+34=1234 彻底杜绝。

6.2 RecordRepository —— 数据访问层（int 分）

lib/data/repositories/record_repository.dart

import 'package:drift/drift.dart';
import '../database/database.dart';

// 类似 Spring Data Repository / DAO
class RecordRepository {
  final AppDatabase _db;
  RecordRepository(this._db);

  // 新增手记 —— amountCents 是 int 分，不是 double
  Future<int> insert({
    required DateTime date,
    required String type,         // 'expense'|'income'
    required int amountCents,    // 分
    int? categoryId,
    String? note,
    int accountId = 1,
    String source = 'manual',
    String? sourceId,        // 手记传 null
    String? merchant,
  }) {
    return _db.into(_db.records).insert(RecordsCompanion.insert(
      date: date,
      type: Value(type),
      amountCents: amountCents,
      categoryId: Value(categoryId),
      note: Value(note),
      accountId: Value(accountId),
      source: Value(source),
      sourceId: Value(sourceId),
      merchant: Value(merchant),
    ));
  }

  // 编辑 —— 必须更新 updatedAt；返回受影响行数（drift update().write() 返回 int）
  Future<int> updateRecord(int id, RecordsCompanion patch) {
    return (_db.update(_db.records)..where((r) => r.id.equals(id)))
      .write(patch.copyWith(updatedAt: Value(DateTime.now())));
  }

  // 查某月记录 —— 半开区间 [start, nextMonthStart)
  Future<List<Record>> getMonthRecords(DateTime month) {
    final start = DateTime(month.year, month.month, 1);
    final nextMonthStart = DateTime(month.year, month.month + 1, 1);
    return (_db.select(_db.records)
          ..where((r) => r.date.isBiggerOrEqualValue(start) &
                         r.date.isSmallerValue(nextMonthStart))
          ..orderBy([(r) => OrderingTerm.desc(r.date)]))
        .get();
  }

  // 当月支出总额 —— 整数 SUM，结果 int，绝不转 double
  Future<int> getMonthExpenseCents(DateTime month) async {
    final start = DateTime(month.year, month.month, 1);
    final nextMonthStart = DateTime(month.year, month.month + 1, 1);
    // 半开区间 [start, nextMonthStart)
    final query = _db.selectOnly(_db.records)
      ..addColumns([_db.records.amountCents.sum()])
      ..where(_db.records.type.equals('expense') &
              _db.records.date.isBiggerOrEqualValue(start) &
              _db.records.date.isSmallerValue(nextMonthStart));
    final row = await query.getSingle();
    return row.read(_db.records.amountCents.sum()) ?? 0;
  }

  // 批量导入去重 —— 性能优化（先查已有 sourceId 集合过滤）；DB 唯一约束兜底
  Future<(int inserted, int skipped)> batchInsertIfNew(
      List<RecordsCompanion> rows) async {
    // 提取非空 sourceId，批量查已有集合（避免逐条查询）
    final sourceIds = rows.map((r) => r.sourceId.value).whereType<String>().toSet();
    final existing = sourceIds.isEmpty
        ? <String>{}
        : (await (_db.select(_db.records)
              ..where((r) => r.sourceId.isIn(sourceIds)))
            .map((r) => r.sourceId).get())
            .whereType<String>().toSet();
    final toInsert = rows.where((r) =>
        r.sourceId.value == null || !existing.contains(r.sourceId.value)).toList();
    await _db.batch((b) => b.insertAll(_db.records, toInsert));
    return (toInsert.length, rows.length - toInsert.length);
  }

  Future<int> deleteRecord(int id) =>
      (_db.delete(_db.records)..where((r) => r.id.equals(id))).go();
}

6.4 BudgetPredictor —— 超支预测（整数运算）

lib/core/budget_predictor.dart

/// 预算超支预测 —— 补鲨鱼记账最大缺口。全程 int 分整数运算。
class BudgetPredictor {
  /// 预测月末总支出（分）
  /// 逻辑：已用 / 已过天数 * 当月总天数
  static int predictMonthEndCents({
    required int usedCents,
    required DateTime now,
  }) {
    final dayOfMonth = now.day;                       // 已过天数（含今天）
    final daysInMonth = DateTime(now.year, now.month + 1, 0).day;
    if (dayOfMonth == 0) return 0;
    // 整数运算：usedCents * daysInMonth / dayOfMonth
    return (usedCents * daysInMonth) ~/ dayOfMonth;
  }

  /// 日均建议（分）：(预算 - 已用) / 剩余天数
  static int? dailySuggestionCents({
    required int budgetCents,
    required int usedCents,
    required DateTime now,
  }) {
    final daysInMonth = DateTime(now.year, now.month + 1, 0).day;
    final remainingDays = daysInMonth - now.day + 1;
    if (remainingDays <= 0) return null;
    final remaining = budgetCents - usedCents;
    return remaining ~/ remainingDays;
  }

  /// 是否超支预测
  static bool willExceed({required int predictedCents, required int budgetCents}) =>
      predictedCents > budgetCents;
}

6.5 UI 消费 Provider（明细页示例）

lib/presentation/detail/detail_page.dart

import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../../core/providers.dart';
import '../../core/utils/money_utils.dart';

// ConsumerWidget = 能用 ref 的 Widget，类似带 @Autowired 的组件
class DetailPage extends ConsumerWidget {
  const DetailPage({super.key});

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final month = ref.watch(currentMonthProvider);
    final summaryAsync = ref.watch(monthSummaryProvider(month));

    return Scaffold(
      appBar: AppBar(title: const Text('明细')),
      body: summaryAsync.when(
        loading: () => const Center(child: CircularProgressIndicator()),
        error: (e, _) => Center(child: Text('出错了: $e')),
        data: (summary) => Column(children: [
          // 显示用 MoneyUtils.formatYuan，不经 double
          Text('支出 ${MoneyUtils.formatYuan(summary.expenseCents)}'),
          Text('结余 ${MoneyUtils.formatYuan(summary.balanceCents)}'),
        ]),
      ),
    );
  }
}
UI 层金额显示的唯一正确方式：MoneyUtils.formatYuan(cents)。禁止 toStringAsFixed、禁止 / 100 转 double 再拼字符串。全局搜 toStringAsFixed 和 / 100 确认无残留。

第一个里程碑验证（第1周末，T1.6）

第 1 周结束时，你应该能用 flutter test 跑通 Repository 单元测试：insert → 查询 → 按月汇总 → batchInsertIfNew 去重 → updatedAt 更新。数据层有测试安全网，后面改 UI 时数据层逻辑有保障。

开发节奏建议

  • 每个功能先写 Repository + 测试，再写 Provider，最后写 UI。数据对了 UI 才有意义。
  • 用 Flutter 热重载调 UI，保存即生效，不用重启 App。
  • 第 4 周务必用自己的真实场景测，连续记一周账，所有"不顺手"的地方都记下来迭代。
  • 每个 Task 完成后单独 commit，格式: feat(T1.3): drift数据库定义。
  • 不要碰云同步，那是 V1 的事。MVP 数据全在本地。
