⚠️ 发现的问题 (均为小问题)

1. 项目未初始化 Git 仓库
CLAUDE.md 规定「每个 Task 完成后单独 commit」，但 git status 返回 not a git repository。建议初始化 git 并按任务拆分提交历史，便于回溯。
2. minSdkVersion 未显式指定
build.gradle.kts 使用 flutter.minSdkVersion 而非显式 minSdk = 21。Flutter 3.44 默认值 ≥ 21 满足要求，但不够显式。如需精确控制可改为硬编码。
3. release 签名使用 debug keys
build.gradle.kts 中 release 构建使用 signingConfig = signingConfigs.getByName("debug")。正式发布前需配置独立签名。
